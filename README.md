# Мой график

Недельный планировщик: работа 5/2 (9:30–18:00), 3 тренировки в неделю (Вт и Чт вечером 20:30–22:30, третья утром в Сб или Вс), вечера после 19:00 — склад, монтаж, отдых или другие дела.

- Открыть: `index.html` в браузере (или по ссылке GitHub Pages).
- Данные хранятся в браузере (localStorage). Резервная копия — в окне «Шаблон».
- «В календарь (.ics)» — выгрузить неделю в Календарь iPhone/Mac.
- На iPhone: Safari → Поделиться → «На экран Домой» — будет как приложение.
